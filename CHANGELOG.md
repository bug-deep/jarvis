## [0.2.0] - 2026-11-18
### Added
- сессии: список, создание, переименование, удаление, автозаголовок
- траектория: карточки инструментов с аргументами, результатом, статусом и временем
- режим подтверждений: «Авто» по умолчанию или «Спрашивать»
- настройки в модальном окне: доступ, папка, сервер, отключение
- кнопка «Стоп» и остановка генерации
- новый интерфейс в стиле Harness: сайдбар сессий, топбар, плотные карточки
### Changed
- история переехала из history.json в sessions/<id>.json

### Added
- Electron-обёртка: окно, иконка, сборки `pack` / `dist:linux` / `dist:win`
- CI для Windows-установщика (`.github/workflows/desktop.yml`)
- выбор адреса облака в настройках и на экране активации
- портативная сборка Windows, `jarvis.json` рядом с `.exe`, ярлык на ПК
- админка: список ожидающих активаций и активация без бота (ADMIN_TG_ID)
- тест бота против фейкового Telegram API: /start, активация, бонус
- живой бот @jarvispcv1_bot через SOCKS-прокси (Telegram с сервера закрыт)
- установщик Windows на NSIS: ярлык, меню «Пуск», удалятор
- приветствие бота без канала больше не обещает бонус
- exe перекрашен: своя иконка и версия Jarvis вместо Electron/GitHub
- портативная сборка: node.exe + Jarvis.bat + окно Chrome, 38 МБ, без установки
- админ-страница `/admin/`: статистика, список пользователей, начисление баланса
- systemd-юниты `jarvis-cloud`, `jarvis-app`, `jarvis-app-tunnel` с автозапуском
- ярлыки «Jarvis Dev» и «Jarvis Admin» на ПК, строки `jarvis-dev` и
  `jarvis-admin` в реестре сервисов

### Changed
- облако слушает LAN (`0.0.0.0:8098`), чтобы админка открывалась с ПК

## [0.1.0] - 2026-11-18
### Added
- облако: активация устройства кодом, выдача и отзыв ключей, баланс, ledger
- шлюз DeepSeek: OpenAI-совместимый `/v1/chat/completions`, SSE, лимиты,
  расчёт стоимости по пиковому тарифу с наценкой
- админ-API: начисление баланса, статистика
- Telegram-бот: активация по коду, бонус за подписку на канал, баланс
- локальный агент: чат, файлы, команды, ссылки, system info
- режимы «Моя папка» и «Весь компьютер», песочница путей
- подтверждение опасных действий в интерфейсе
- UI: активация, чат, статистика, настройки
- тесты: цены, песочница, активация, баланс, идемпотентность бонуса
