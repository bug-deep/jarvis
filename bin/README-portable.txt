Джарвис — портативная версия для Windows.

1. Распакуй архив целиком в любую папку (например, на рабочий стол).
2. Запусти Jarvis.bat.
3. Откроется отдельное окно Джарвиса.

Важно:
- Не закрывай свёрнутое окно "Jarvis" в панели задач — это и есть программа.
- Чтобы выключить Джарвиса, закрой это окно.
- Первый запуск: Джарвис покажет код из 8 символов.
  Отправь его боту @jarvispcv1_bot — и всё заработает.

Ничего устанавливать не нужно: Node.js уже лежит внутри.
