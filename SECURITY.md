# Безопасность

Это домашний проект, не предназначенный для внешнего использования без
отдельного решения. Тем не менее:

- уязвимость нашли — сообщи владельцу напрямую (не публичным issue);
- в отчёте: что воспроизвести, что происходит, чем это грозит;
- ответ — в течение 7 дней; исправление — по возможности в том же месяце.

Секреты в этом репозитории не хранятся: значения лежат в `~/Harness/secrets/`,
в git попадает только `*.env.example` без значений.
