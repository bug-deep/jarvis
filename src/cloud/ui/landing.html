JARVIS

ИИ-помощник на твоём компьютере

Пишет код, работает с файлами, выполняет команды и отвечает голосом.

Скачать для Windows Портативная версия — 38 МБ, без установки
  1. Скачай установщик и запусти его.
  2. Открой Джарвиса — он покажет код из 8 символов.
  3. Отправь код боту @jarvispcv1_bot — он активирует устройство.

Если Windows покажет «Неизвестный издатель» — нажми «Подробнее» → «Выполнить всё равно». Файл не подписан сертификатом, это не вирус.
